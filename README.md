# GPT-2 — Training and validate via Telegram bot

> Based on [*Build a Large Language Model (From Scratch)*](https://www.manning.com/books/build-a-large-language-model-from-scratch) by Sebastian Raschka.

A GPT-2 implementation from scratch in PyTorch. Supports several modes: importing OpenAI weights, fine-tuning on custom data, running a Telegram bot, and training/running a spam detector.

---

## Requirements

```bash
pip install torch tiktoken typeguard python-dotenv pyTelegramBotAPI numpy pandas
```

Create a `.env` file in the project root:

```env
TELEGRAM_TOKEN=your_telegram_bot_token
```

---

## Modes

All modes are launched through the single entry point `main.py`.

### 1. Import GPT-2 weights from OpenAI

Downloads pretrained GPT-2 weights and saves them to a model file.

```bash
python main.py --mode import --llm-file model.pth --llm-size 124M
```

| Argument | Description |
|---|---|
| `--llm-size` | Model size: `124M`, `355M`, `774M`, `1558M` |
| `--llm-file` | Path to save the model file |

---

### 2. Import weights for the spam detector

Downloads pretrained GPT-2 weights for subsequent fine-tuning as a spam classifier.

```bash
python main.py --mode import-spam --llm-file model_spam.pth --llm-size 124M
```

---

### 3. Fine-tune on custom data

Fine-tunes the model on a text file. Supports resuming from a checkpoint.

```bash
python main.py --mode train --llm-file model.pth
```

Uses `train_data/the-verdict.txt` as the data source by default. You can override the source file by running `main_train.py` directly:

```bash
python main_train.py --llm-file model.pth --llm-source my_text.txt
```

During training, the model generates a continuation of `"Every effort moves you"` after each epoch so you can monitor progress. A train/valid loss plot is shown at the end.

---

### 4. Train the spam detector

Fine-tunes the model on an SMS spam dataset to classify messages as spam or not spam.

```bash
python main.py --mode train-spam --llm-file model_spam.pth
```

---

### 5. Telegram bot

Runs a bot that responds to messages using the loaded model.

```bash
python main.py --mode tg-bot --llm-file model.pth --llm-size 124M
```

The bot accepts a text message and returns a continuation generated by the model.

---

### 6. Spam detector Telegram bot

Runs a bot that classifies incoming messages as spam or not spam.

```bash
python main.py --mode tg-bot-spam --llm-file model_spam.pth --llm-size 124M
```

## Project Structure

```
.
├── main.py                  # Entry point, mode routing
├── main_import.py           # Import weights from OpenAI GPT-2
├── main_import_spam.py      # Import weights for the spam detector
├── main_train.py            # Training loop
├── main_train_spam.py       # Spam detector training loop
├── main_tg_bot.py           # Telegram bot
├── main_tg_bot_spam.py      # Spam detector Telegram bot
├── cfg.py                   # Model configs GPT_MODEL_CONFIGS
├── aliases.py               # Types LlmSize, LLM_SIZES
├── classes.py               # GptModelProgress (checkpoint dataclass)
├── components/
│   ├── gpt_model.py         # GptModel architecture
│   ├── gpt_agent.py         # GptModelAgent (text generation)
│   ├── transformer.py       # Transformer block
│   ├── causal_attention.py  # MultiHeadAttention
│   ├── ml.py                # MachineLearning (train/eval loop)
│   ├── evaluator.py         # ModelEvaluator (metrics, plots)
│   └── dl.py                # DataLoader for text data and SpamDataset
├── import_gpt2/
│   ├── gpt_download.py      # Download GPT-2 weights from OpenAI
│   └── gpt_importer.py      # Load weights into GptModel architecture
├── train_data/
│   |── the-verdict.txt      # Sample training data
│   |── train.csv            # Sample training data for spam classifier
│   └── validation.csv       # Sample valid training data for spam classifier
└── .env                     # TELEGRAM_TOKEN (do not commit)
```

## Typical Workflow

```bash
# 1. Import pretrained weights
python main.py --mode import --llm-file gpt2_124m.pth --llm-size 124M

# 2. Fine-tune on custom data
python main.py --mode train --llm-file gpt2_124m.pth

# 3. Run the Telegram bot
python main.py --mode tg-bot --llm-file gpt2_124m.pth --llm-size 124M

# 4. Import pretrained weights for the spam detector
python main.py --mode import-spam --llm-file gpt2_124m_spam.pth --llm-size 124M

# 5. Fine-tune the spam detector on custom data
python main.py --mode train-spam --llm-file gpt2_124m_spam.pth

# 6. Run the spam detector as a Telegram bot
python main.py --mode tg-bot-spam --llm-file gpt2_124m_spam.pth --llm-size 124M
```
